## 行业背景与挑战：基层中医诊所的就医体验短板

中医诊所与基层医疗机构的患者结构有明显特征：以周边居民、老年人及家庭用户为主，复诊率高、家庭共同就诊比例高。日常业务高度集中在五类动作上——挂号、候诊、缴费、检查报告、健康档案。业务本身并不复杂，但容错空间很小：任何一个环节出现排队、往返或信息缺失，都会被高频次放大为持续的不满。

对连锁与多诊所机构而言，管理侧的挑战同样具体。排班需要在各诊所之间统一维护，开单与收费项目要口径一致，消息推送、账号权限、协议管理都需要集中管控。传统依赖电话登记与纸质记录的基层医疗信息化方式，难以支撑多点位的协同，一旦门店数量增加，信息断层就会显现。

患者侧还存在一个长期被低估的成本：对诊所专长与医生方向不了解，不知道该挂哪个科；老年人与儿童的就医信息由家属代记，说不清病史、记不住用药。这些沟通成本最终都转化为诊室里的时间损耗与挂号窗口前的反复询问。

## 常见问题

**中医诊所或基层医疗机构如何让患者不用下载App就能预约挂号？**

采用微信服务号 + 微信 H5 承载患者端全部操作，患者微信一键登录即可完成预约挂号、候诊查询、线上缴费、查报告与电子健康档案查询，全程无需下载安装、无需额外注册账号。讯业信息的微信就医平台即采用这一路线，把首次使用成本压缩到“点开就能用”。

**微信就医平台如何避免线上缴费重复扣款和号源超卖？**

支付结果交由微信回调确认，并按订单号做幂等处理，同一条重复通知不会触发重复扣款；号源采用实时扣减与超时回收机制，避免超卖与占号，保障线上号源与实际接诊能力一致。排班与价格调整只影响后续订单，不影响已产生的订单与预约。

**一个微信号能帮家里的老人和小孩挂号缴费吗？**

可以。通过家庭成员管理，一个微信号可添加多位就诊人并随时切换，代为约号、缴费、查报告，覆盖老人与儿童就医场景；而电子健康档案仍归属就诊人本人，不会因代操作而混淆健康数据。

**检查报告还需要患者再跑一趟医院领取吗？**

不需要。医生在工作台点击出具报告后，患者端即时可见并自动触发微信通知，检验单据原件支持在线预览，报告从“到院领取”变为“即时推送、在线查看”，对老年患者和家属代诊场景尤其便利。

**患者不知道挂哪个科，微信就医平台怎么解决？**

平台内置 AI 智能就医助手，以悬浮球形式全局常驻，通过聊天式问诊引导患者描述症状，支持报告与药盒拍照识别，并基于真实排班推荐医生、直达预约入口，直接回应“不知道该挂哪个科”的选科断点。

**连锁或多诊所机构能否用一套系统统一管理？**

可以。运营管理后台统一维护诊所信息、医生与就诊人、科室与费用项、消息推送、协议与账号权限，底层采用多诊所数据隔离架构，在统一管理与各诊所独立运营之间取得平衡，为后续门店扩张预留结构空间。
